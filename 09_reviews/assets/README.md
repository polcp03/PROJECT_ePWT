# Assets

The project's images. The decks and the public README pull from here.

| Folder | What is in it | Edited by hand? |
|---|---|---|
| `photos/` | Real photos of the quad, already converted to JPG | **Yes** — new photos are added here |
| `photos/_originals/` | The iPhone HEIC files as they came out | No |
| `crops/` | Derived crops (16:9 bands and verticals) | **No — generated** |
| `figures/` | Diagrams and plots generated with matplotlib | **No — generated** |
| `web/` | Downloaded product images, with their source | No |
| `video/` | Raw clips for a short portfolio video (from 6-Nov). **Not in Git**: too large; on the PC only | Yes — new clips here |

`crops/` and `figures/` are regenerated by the command below, and **are not in Git**: they are
derived from `photos/`, which is. On a new machine, run it before building a deck.

```bash
./.venv/Scripts/python.exe 09_reviews/_figures.py
```

## How to add a new photo

1. Copy the HEIC to `photos/_originals/`.
2. Convert it to JPG in `photos/` (`pillow-heif` is already in the venv).
3. If a slide needs a crop, add the entry to the `jobs` list in `_figures.py::crops()` and run
   it again. **Never crop by hand:** the crop has to be reproducible.
