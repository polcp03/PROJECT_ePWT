# 02_knowledge — what I know, not what I have read

No theory is copied here: the theory is in the books and the lessons. What stays here is
**what I can explain**, taken from my answers in the Bench and corrected.

| File | What it is | Who writes it |
|---|---|---|
| `motor-inverter.md` (and one per topic) | My explanations, in my words, already corrected | Claude copies from my answers; I rewrite whatever doesn't sound like me |
| `software.md` | How I check and steer the code the AI writes | Claude, when grading |
| `mistakes.md` | Every mistake I have made, with the correct version and when to ask me again | Claude, when grading |
| `sources.md` | Which book and which chapter for each topic | Claude |
| `visuals/` | Interactive figures used by the lessons | Claude |
| `method/` | Tools: Git, Claude Code sessions | — |

**How it is used:**
1. I answer in the Bench.
2. The Bench grades it; on Sunday Claude (skill `corregir`) copies here what was said well and the mistakes.
3. Before each exam, the mistakes still open in `mistakes.md` come back.
   A mistake is closed when I answer it right **twice, on different days**.
